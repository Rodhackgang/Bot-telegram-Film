## Présentation

Bot Telegram qui présente un catalogue de canaux et de liens sous forme de boutons, à partir d'un simple fichier texte modifiable sans toucher au code.

**Pourquoi ce choix.** Confier la liste à un fichier texte permet de la mettre à jour sans redéploiement ni compétence technique.

---

## Ce que fait le projet

- **Liste pilotée par fichier** — `urls.txt` génère les boutons
- Message d’accueil illustré
- Jeton lu depuis l’environnement, absence détectée au démarrage
- Serveur HTTP minimal pour rester éveillé sur un hébergement gratuit
